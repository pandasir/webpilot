# 测试中心视觉改版验收

日期：2026-10-18。平台：macOS arm64，Node v26.7.0，仓库锁定的 Playwright/Chromium。

## 改版范围

在既有信息架构、路由、接口与可访问名称不变的前提下重做视觉层，只改 `dashboard-ui/src/style.css` 与 `dashboard-ui/src/main.tsx` 中的画面呈现：

- 色彩系统改为暖中性底色（`#f5f5f1`）+ 白色工作区，侧栏改为浅色并保留选中态描边，强调色统一为低饱和墨绿（`#3a6f5d`）；通过/失败/阻塞/执行中的状态色降低饱和度并配浅色描边，仅用于小面积标签与圆点。
- 字号层级整体上调：11px 的正文与列表信息提升到 11.5–13.5px，状态徽标改为圆角胶囊，表头与辅助信息统一为 10.5–11px；行高与间距加大，列表行高由 87px 收紧为 76px 但可读性更好。
- 总览统计改为带边框的卡片式一行四列（移动端 2×2），不再是大面积灰底。
- 运行列表改为带圆角与细边框的表格卡片，表头悬浮在顶部；选中行出现墨绿左侧标记，进度条按结果着色（通过绿、失败红、执行中蓝灰）。
- 详情页：标题区、元信息改为胶囊标签，时间线加大字号，选中步骤使用白底描边；内容区分页标签改为下划线式，并在标签之间保留点击区域。
- 已结束运行默认不再显示空白直播区：自动展示最近一张步骤截图（带「运行已结束」标注，仍可点击放大），下面保留“查看录像”入口。
- 截图页签的图片网格改为自适应（桌面 2 列、窄屏 1 列），图片高于视口时可正常滚动。
- 320px 下运行名称最多两行、日期与耗时允许换行，避免出现 “10/18 12:25 · 6…” 这类被截断的时间。

功能、文案、ARIA 名称、菜单悬停关闭逻辑、批量管理与删除确认行为均未改变。

## 验证结果

- `npm run typecheck`：通过。
- `npm run build`：通过（CSS 36.0 kB → gzip 7.6 kB）。
- `npm run test` 全量浏览器与单元回归：65 项全部通过，包含两路 MCP 直播、服务重启、截图/报告/录像、归档/撤销/批量管理/永久删除/重命名、历史记录与不可信内容按文本展示。
- 额外预览脚本在改造前后的临时演示数据上逐页截图核对：总览、批量管理、并排观看、详情（实时画面/步骤详情/截图/报告）、管理菜单、删除弹窗、归档空状态、状态筛选。
- 375/390/414/600/768/900/1024/1280/1440/320/360px 共 11 档宽度 × 总览 / 归档 / 并排观看 / 详情 4 个页面：无横向溢出，无浏览器脚本错误。
